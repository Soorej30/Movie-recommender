Support Vector Machines (SVMs)

Overview

Support Vector Machines classify movies into reception categories by finding the boundary that best separates classes in attribute space, using different kernel functions (linear, polynomial, and radial basis function) to allow for straight or curved decision boundaries. Multiple kernels will be compared against each other and against Naive Bayes and decision trees on the same labeled movie data to see which decision boundary shape fits the relationship between movie attributes and reception best.
