GradientBoosting

Overview

Gradient boosting also builds trees one after another, but each new tree is fit to the residual errors (the gradient of the loss) of the ensemble so far, not to reweighted rows. It will be applied to the same reception-class task used on the Naive Bayes, Decision Trees and AdaBoost tabs so the results can be compared directly.
