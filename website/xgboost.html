XGBoost

Overview

XGBoost (eXtreme Gradient Boosting) is a fast, regularized implementation of gradient boosting. It adds penalties on tree complexity, built-in handling of missing values and column subsampling. It will be applied to the same reception-class task so it can be compared with AdaBoost and the decision trees.
